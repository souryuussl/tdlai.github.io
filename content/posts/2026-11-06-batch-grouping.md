把“课堂分组”交给 AI，不是让它在聊天窗口里给一份名单，而是让它直接写一个能在浏览器里打开、能反复使用的小工具。下面这套做法用 DeepSeek 就能完成：准备一份学生名单，写清楚规则，让 AI 生成单文件 HTML，课堂上打开就能用。

![在 DeepSeek 中粘贴提示词后，它直接输出完整 HTML；在浏览器打开就是右侧这个分组工具：名单、分组设置和带组名、平均分的小组卡片都在同一页面](/images/batch-grouping-tool.png)

<!--more-->

## 需求目标

面向班主任或任课教师：把 40 人左右的班级名单，按成绩或综合评级分成若干小组，要求组内强弱搭配、各组平均分接近，并能输出小组卡片和可复制的分组名单。

工具要满足三个条件：

- 单文件 HTML，双击就能在浏览器打开，不需要安装软件；
- 数据只在本地浏览器里处理，不上传学生信息；
- 生成结果能直接打印，或者复制为纯文本继续调整。

## 怎么做

### 1. 准备名单

从花名册导出 CSV 或 Excel，只保留三列：姓名、成绩（或综合评级）、备注（如“不同组：张三”）。删掉学号、住址、家长电话等无关信息，避免把敏感数据交给 AI。

### 2. 把需求写成提示词

下面这版提示词把页面结构、分组规则、趣味性和输出要求都写清楚了，可以直接复制，把示例人数和组数改成自己的：

```text
你是一名资深前端工程师，同时也是班主任。请开发一个「课堂分组工具」，只做分组，不做座位表或座次安排。用于真实课堂教学。

【目标】
生成一个单文件 HTML（CSS/JS 全内联），双击即可在 Chrome/Edge 离线运行。核心流程：粘贴名单 → 自动分组 → 手动调整 → 复制/打印。

【页面结构】
1. 顶部：工具名、说明、打印、重新开始。
2. 左侧（桌面）/上方（移动）：名单输入 + 分组设置；右侧/下方：分组结果。
3. 底部统计：总人数、组数、各组平均分、最高/最低组均分。
4. 桌面左右分栏，移动上下排列；1366×768 和手机宽度不横向溢出。
5. 只做分组视图，不要出现座位表、排/列、讲台、座位禁用等任何座位相关模块。

【名单格式】
- 每行：姓名,成绩,备注；支持中英文逗号和 Tab。
- 备注可为空；支持“不同组：张三”或“不同组：张三、李四”。
- 提供“填入示例名单（16 人）”和“清空”。
- 处理空行、重复姓名、非数字成绩、缺成绩；用页面提示条，不用 alert。

【分组规则】
- 小组数默认 8，每组人数差 ≤ 1。
- 按成绩降序，蛇形分配到各组，保证组内强弱搭配、组间平均分尽量接近（示例数据 ≤ 3 分）。
- 尽量满足“不同组”约束；无法满足时在学生旁标黄色冲突提示。
- “重新分组”结果稳定；另设“随机微调”换一种组合。

【分组结果与趣味性】
- 每组一张卡片：组名、emoji、颜色条、成员、人数、平均分、口号。
- 趣味模式（可开关）：随机组名（动物/水果/星球/颜色等）+ emoji + 口号 + 1.5 秒彩纸/星星动画 + “换一批组名”。
- 简洁模式：第 1 组、第 2 组……，无动画。
- 成员用彩色胶囊展示；可拖动到其他组，或点击学生再点目标组移动；统计实时更新。
- 卡片轻微淡入/上浮，不要过度。

【手动调整与导出】
- 支持拖动/点击移动学生到其他组。
- “复制分组结果”输出纯文本：
  第 1 组（平均分 86.5）：张三、李四、王五
- “打印”只保留分组卡片和统计条，隐藏输入区、设置区、按钮、动画；A4 横向，每行 2–4 张卡片，避免截断。

【视觉】
- 轻快温暖，主色柔和粉 #d6336c + 淡蓝 #4f8cff，浅色背景。
- 卡片圆角 14–18px、柔和阴影、留白充足；按钮有 hover/active/disabled。
- 分组卡片用不同柔和配色，文字对比度足够。
- 系统中文字体，标题加粗，正文 15–16px；用 emoji 代替外部图片。
- 空状态/错误状态有友好文案，不出现空白页。

【技术约束】
- 单文件 HTML，内联 CSS/JS；无 CDN、外部字体、外部图片、网络请求。
- 原生 JS，不依赖 React/Vue/jQuery；数据只在本地处理。
- 代码完整可运行，禁止“省略”“同上”等占位；关键函数加中文注释。
- 兼容 Chrome/Edge 最近两个大版本。
- 输出被截断时，从截断处继续，不重复已输出部分。

【输出】
1. 先输出完整 HTML 代码块。
2. 后用 5–8 行说明：保存、粘贴名单、重新分组、手动调整、复制/打印。
3. 不要长篇解释。

【自检】
- 16 人示例 → 8 组，组间平均分尽量接近（示例数据 ≤ 3 分）。
- “不同组”约束尽量生效，冲突有提示。
- 拖动/点击移动学生后统计实时更新。
- 趣味模式开关、换组名、动画正常。
- 复制格式正确；打印只有分组卡片和统计条。
- 1366×768 和手机宽度无横向滚动。
- 页面无任何座位表、排/列、讲台、座位禁用内容。
```

### 3. 让 DeepSeek 生成代码

把提示词粘贴到 DeepSeek，等待它输出完整 HTML。第一次生成后，不要急着用，先做三件事：

- 检查代码是否完整，有没有“省略中间部分”的注释；
- 用 5–10 人的小名单测试，确认分组人数和平均分正确；
- 再用真实班级名单测试，重点看组间平均分是否接近、“不同组”约束是否生效。

如果结果不对，不要重新开一个对话，直接在原对话里补充：

- “第 3 组和第 5 组平均分相差 5 分，请调整分配算法，确保差距不超过 3 分。”
- “分组卡片在手机上太挤，请改成单列布局。”
- “打印时按钮也出现了，请用 @media print 隐藏按钮。”

### 4. 保存并试用

把 DeepSeek 输出的代码复制到记事本，保存为 `class-grouping.html`（编码选 UTF-8），双击用浏览器打开。建议先在 Chrome 或 Edge 里测试，确认：

- 粘贴名单后能正确分组；
- “重新分组”结果稳定，“随机微调”能换一种组合；
- 打印预览只包含分组卡片和统计条；
- 手机浏览器也能正常操作。

### 5. 放进真实课堂

上课前把 HTML 文件拷到教室电脑，或者发到班级群让课代表在自己的电脑上打开。需要临时调整时，直接改名单或点“重新分组”，不需要重新找 AI 生成。用完后把文件留在本地，下次换一批学生，替换名单即可复用。

## 注意事项

- **不要上传真实学生信息。** 提示词里只写规则，不要把姓名、成绩、家长电话发给 AI；生成代码后再在本地粘贴名单。
- **AI 生成的代码需要检查。** 尤其是平均分计算、人数分配和打印样式，建议用小名单手工核对一遍。
- **准备一个备用方案。** 如果教室电脑浏览器版本太旧，提前在自己电脑上生成一份分组结果，打印出来带到教室。
- **把提示词存下来。** 下次换班级或换规则，只需要改提示词里的数字和条件，不用从零开始。
