很多人收藏了几十个“万能提示词”。真到用的时候，还是会出现两种情况：要么答得太泛，要么答得挺热闹，却不是你要的东西。

于是继续找模板，继续收藏。

问题可能不在模板，而在你还没告诉它三件事：**能做什么、不能做什么、必须做什么。**

<!--more-->

## 01 一个熟悉的翻车现场

一位班主任想让 AI 帮忙写家长会发言稿。

这位班主任输入：“你是优秀的班主任，帮我写一篇家长会发言稿。”

几秒钟，一篇文采不错的稿子出来了。开头是“亲爱的同学们”，通篇在鼓励大家努力学习，结尾还带着几句口号。

问题是，家长会是对家长说的，不是对学生说的。这位班主任让 AI 改，AI 把“同学们”改成“各位家长”，又顺手加了三段“家校共育”的排比。再改，语气又变得像领导讲话。

改到第五版，这位班主任放弃了，自己打开空白文档重新写。

这个场景里，AI 并不是不会写发言稿。它只是**不知道这场会的听众是谁、要讲多久、重点是什么、什么话不能说**。这位班主任给了一个角色，却没给边界。

角色只是起点，不是全部。

## 02 第一问：它能做什么

第一个问题，是把任务说到可执行。

“帮我写点东西”不是任务；“把这份 800 字的家长会发言，改成 300 字、适合发在班级群里的通知”才是任务。

一个可执行的任务，通常包含四个要素：

| 要素 | 要回答的问题 | 例子 |
|---|---|---|
| 对象 | 给谁看 / 给谁用 | 三年级学生家长 |
| 目标 | 看完要做什么 | 知道明天春游的集合时间和物品清单 |
| 范围 | 基于什么材料 | 只使用我提供的发言稿，不额外发挥 |
| 形式 | 输出成什么样 | 300 字以内，分 3 条，语气亲切 |

再看一个教学场景：让 AI 批改三年级作文。

模糊的说法是：“帮我批改这篇作文。”

可执行的说法是：“你是三年级语文老师。请从内容、结构、语言三个方面批改这篇作文，每个方面指出一个优点、一个需要修改的地方，并给出修改示例。不要打分数，不要写评语套话，总字数控制在 300 字以内。”

后者不一定一次就完美，但至少你知道它在做什么，也知道哪里不满意时该改哪一句。

## 03 第二问：它不能做什么

第二个问题，是划出边界。

边界包括三类：

1. **不做什么**：不替老师打最终分数，不写学生评语，不生成与任务无关的内容。
2. **不碰什么**：不处理真实姓名、家长电话、成绩排名等敏感信息；不把内部文件上传到不可控的平台。
3. **不超出什么**：不引用没有依据的政策，不编造学校规定，不假装自己知道。

比如作文批改助手，可以加三条：

- 不要给作文打分，最终分数由老师决定；
- 不要评价学生本人，只评价这一次的作文；
- 如果作文内容涉及家庭隐私，不要复述，只指出“此处建议面谈”。

边界不是越多越好。三到五条关键约束，通常比二十条互相打架的规则更有效。写太多，模型反而容易顾此失彼。

## 04 第三问：它必须做什么

第三个问题，是定下硬性要求。

“必须做”包括：必须遵守的格式、必须引用的材料、必须标注的不确定性、必须完成的检查。

还是作文批改助手：

- 每条建议必须引用学生原文中的一句话；
- 修改示例必须保留学生的原意，不能替学生重写一篇；
- 不确定的地方必须写“建议老师复核”，不能自己下结论；
- 最后必须用表格输出：维度 / 优点 / 问题 / 修改示例。

这里有一个很实用的细节：**把最重要的“必须做”放在提示词前面。**

提示词一长，后面的内容容易被忽略。就像开一场长会，最后十分钟布置的任务，散会后常常没人记得。把硬性要求前置，比在末尾补一句“注意不要……”更可靠。

## 05 把三问拼成一份人设

把三个问题按顺序写下来，就是一份结构化的“人设”。

常见的五段式是：**角色 → 目标 → 技能 → 工作流 → 输出格式**。再加上“不能做”和“不确定时怎么办”，就够用了。

下面是一份可以直接改用的模板：

```text
你是【三年级语文老师，擅长作文批改】。

【能做】
- 批改三年级学生的记叙文，从内容、结构、语言三个方面给出建议。
- 每次批改只针对这一篇作文，不扩展到其他学生。

【不能做】
- 不给作文打分，最终分数由老师决定。
- 不评价学生本人，只评价这一次的作文。
- 不复述作文中涉及家庭隐私的内容。

【必须做】
- 每条建议必须引用学生原文中的一句话。
- 修改示例必须保留学生原意，不能替学生重写。
- 不确定的地方写“建议老师复核”。
- 最后用表格输出：维度 / 优点 / 问题 / 修改示例。

【工作流】
1. 先通读全文，用一句话概括这篇作文写了什么。
2. 按内容、结构、语言三个方面，各找一处优点和一处问题。
3. 针对问题给出修改示例。
4. 按表格格式输出。

【输出格式】
- 开头一句话总评，不超过 50 字。
- 中间一张四列表格。
- 结尾一句给老师的提示，不超过 30 字。

【不确定时】
- 如果作文内容不完整或看不清，请先说明缺什么，不要猜测。
```

这份模板不是咒语。换一个任务，角色、技能、工作流都要跟着换。真正可复用的，是“三问”的顺序，不是某一段固定文案。

## 06 两个容易被忽略的细节

### 细节一：重要的往前放

模型的注意力不是平均分配的。提示词越长，越靠后的要求越容易被稀释。

所以顺序建议是：

1. 角色和目标；
2. 不能做的硬边界；
3. 必须做的硬要求；
4. 工作流和格式；
5. 语气、风格等软要求。

如果某条要求特别重要，可以在开头和结尾各说一次，但不要整篇重复。

### 细节二：提示词是护栏，不是锁

提示词能管住大多数情况，但总有一小部分会漏过去。

你写了“不要回答与作文无关的问题”，它还是可能顺嘴答一句；你写了“不要编造”，它还是可能给出一个看起来很合理的错误答案。这不是你写错了，而是概率模型的本性。

所以，关键场景要加第二道保险：

- **格式校验**：输出必须是表格 / JSON / 固定字段，缺了就重试；
- **关键词检查**：出现“保证”“一定”“百分百”这类绝对化表述时，人工复核；
- **人工抽查**：重要内容不能直接发布，至少抽看一部分；
- **权限控制**：不让它直接改数据库、发通知、提交表单。

提示词负责“让它大概率做对”，程序和人工负责“兜住那小概率”。

## 07 一张检查清单

下次写提示词之前，可以按这张表过一遍：

| 检查项 | 问自己 |
|---|---|
| 对象 | 输出是给谁看的？读者是谁？ |
| 目标 | 看完之后，对方要能做什么？ |
| 范围 | 只能基于哪些材料？能不能自由发挥？ |
| 能做 | 具体任务、数量、长度、语气，写清楚了吗？ |
| 不能做 | 有哪些绝对不能碰的内容？ |
| 必须做 | 有哪些硬性格式、引用、标注要求？ |
| 顺序 | 最重要的要求，是不是放在了前面？ |
| 示例 | 有没有给一个“好答案长什么样”的例子？ |
| 兜底 | 它不知道时，应该怎么回答？ |
| 复核 | 哪些输出必须人工检查？ |

这张表不需要每次全填。任务越重要，填得越完整。

## 写在最后

提示词模板可以收藏，但不要指望背模板解决所有问题。

真正决定效果的，是你有没有把三件事说清楚：

- **它能做什么**——任务、对象、范围、形式；
- **它不能做什么**——边界、禁区、敏感信息；
- **它必须做什么**——格式、引用、标注、检查。

把这三问答完，再套模板，模板才有意义。
